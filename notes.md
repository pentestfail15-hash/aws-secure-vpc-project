# AWS Secure VPC Notes

## VPC
Provides an isolated virtual network in AWS.

## Public Subnet
A subnet with a route to the Internet Gateway.

## Private Subnet
No direct internet access. Suitable for databases and backend services.

## Internet Gateway
Allows internet connectivity for resources in public subnets.

## Route Table
Defines how traffic is routed between subnets and external networks.

## Security Group
Acts as a virtual firewall controlling inbound and outbound traffic.

## EC2
Virtual machine hosted inside the VPC.
